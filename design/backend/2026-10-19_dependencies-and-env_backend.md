# 2026-10-19 — Зависимости и окружение (backend)

## Назначение документа

Воспроизводимое окружение бэкенда: менеджер зависимостей (uv), минимальный набор пакетов в `pyproject.toml`, разделение main/dev, требуемая версия Python, команды запуска.

## Менеджер зависимостей и Python

- **uv** — единый инструмент: создание виртуального окружения, разрешение и установка зависимостей, запуск команд. Pip/poetry/pip-tools не используются.
- **Python `>=3.11`** — зафиксировано в `pyproject.toml` (`requires-python = ">=3.11"`). Основание: актуальный стек FastAPI/SQLAlchemy 2.x/Pydantic v2, production-опыт владельца. Более старые версии не поддерживаются.
- Файл блокировки `uv.lock` — в репозитории (воспроизводимость окружения).

## pyproject.toml (проектный минимум)

Расположение: `backend/pyproject.toml`. Зависимости API-сервиса и скриптов — в одном проекте (монорепозиторий MVP, единое окружение).

Группа **main** (runtime, используется и API, и скриптами):

| Пакет | Назначение | Ограничение версии |
|---|---|---|
| `fastapi` | Веб-фреймворк (ADR-0002) | `>=0.115,<1.0` |
| `uvicorn[standard]` | ASGI-сервер dev-запуска | `>=0.30` |
| `sqlalchemy` | ORM, доступ к БД | `>=2.0,<3.0` |
| `alembic` | Миграции схемы БД | `>=1.13` |
| `pydantic` | DTO и валидация | `>=2.7,<3.0` |
| `pydantic-settings` | Конфигурация из окружения | `>=2.4` |
| `httpx` | HTTP-клиент скриптов сбора (MOEX ISS, disclosure) | `>=0.27,<1.0` |
| `beautifulsoup4` + `lxml` | Разбор HTML-источников (disclosure.ru) | `>=4.12` / `>=5.2` |

Драйвер БД: для SQLite (ADR-0001, целевой вариант MVP) сторонний драйвер не нужен — встроенный `sqlite3`. Если ADR-0001 зафиксирует PostgreSQL — добавляется `psycopg[binary] >=3.1` (единственное изменение зависимостей).

Группа **dev** (не требуется для запуска сервиса):

| Пакет | Назначение |
|---|---|
| `pytest` | Тесты (API, парсеры, loader) |
| `ruff` | Линтер и форматтер (единый инструмент вместо flake8+black) |

Сознательно **не включаются** (вне MVP): celery/RQ + redis (фоновых задач нет), aiohttp/asyncpg (синхронный стек), auth-библиотеки, open telemetry, pre-commit.

## Команды (контракт окружения)

Выполняются из каталога `backend/`:

```bash
uv sync                 # создать .venv и установить main+dev по uv.lock
uv sync --no-dev        # установка только runtime-зависимостей
uv run alembic upgrade head          # инициализация/обновление схемы БД
uv run uvicorn app.main:app --reload # dev-сервер API: http://127.0.0.1:8000
uv run python -m scripts.fetch_tickers_moex           # сбор тикеров
uv run python -m scripts.fetch_meetings_disclosure    # сбор собраний и отсечек
uv run pytest           # тесты
uv run ruff check . && uv run ruff format --check .   # линт
```

Документация API (автогенерация FastAPI): `http://127.0.0.1:8000/docs` (Swagger UI) — используется и фронтенд-разработчиком для сверки с [API-контрактом](./2026-10-19_api-контракт_backend.md).

## Конфигурация окружения

- Файл `.env` (шаблон `.env.example` в репозитории, сам `.env` — в `.gitignore`). Переменные — по таблице конфигурации в [архитектуре бэкенда](./2026-10-19_архитектура-бэкенда_backend.md) (префикс `DIVCAL_`).
- Секретов нет. Все переменные имеют значения по умолчанию: после `uv sync` сервис стартует без `.env` на SQLite-файле `./divcal.db`.

## Порядок первого запуска (воспроизводимость)

1. Установлен uv и Python >= 3.11.
2. `cd backend && uv sync`
3. `uv run alembic upgrade head`
4. `uv run python -m scripts.fetch_tickers_moex` — первичное наполнение справочника тикеров.
5. `uv run python -m scripts.fetch_meetings_disclosure` — первичное наполнение событий.
6. `uv run uvicorn app.main:app --reload` — API готов для фронтенда.
