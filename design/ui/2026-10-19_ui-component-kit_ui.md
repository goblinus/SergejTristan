# Состав UI-кита MVP

Дата: 2026-10-19
Область: ui

Перечень компонентов, необходимых и достаточных для реализации экранов S1/S2 по вайрфреймам `2026-10-19_вайрфреймы_ui.md`. Компоненты вне MVP (таб-центры, date-range picker, wizard и т.п.) не проектируются.

Нумерация: `C-<nn>`. Для каждого: назначение, варианты, состояния.

---

## C-01. AppBar (шапка приложения)

- Назначение: навигация между S1/S2, глобальные действия.
- Состав: логотип+название, вкладки «Календарь»/«Мои сторожки», справа индикатор обновления + кнопка «⟳ Обновить».
- **Бейдж-счётчик сторожков (Р-9)**: на вкладке «Мои сторожки» — компактный круглый бейдж с числом сторожков в статусах `hot`/`critical` (данные — серверные статусы из `GET /api/v1/watchlist`, клиентского пересчёта нет, см. `2026-10-19_индикация-сроков_ui.md`, §4). Плашка нейтральная: фон `--warn-container`, текст `--warn` — не «сигнал тревоги», а приглашение заглянуть; красный (`--danger`) для бейджа не используется, чтобы не смешивать с ошибками. **Бейдж скрыт при 0 и до первой загрузки списка сторожков** (вместо 0/серого «?» — отсутствие элемента).
- Состояния: обычное; loading (тонкая полоса прогресса под шапкой — бейдж в это время показывает последнее известное значение); offline (бейдж «нет соединения», счётчик сохраняет последнее значение).
- На мобильной ширине навигация переезжает в C-02.

## C-02. BottomNav (мобильная навигация, ≤640px)

- Назначение: замена вкладок AppBar на мобильной компоновке.
- Состав: 2 пункта — «Календарь» (`calendar_month`), «Мои сторожки» (`notifications_active`).
- **Бейдж-счётчик (Р-9)**: тот же счётчик сторожков `hot`/`critical`, что и в C-01, располагается в правом верхнем углу иконки пункта «Мои сторожки» (стандартное Material-положение badge). Стилистика и правила скрытия идентичны C-01: плашка `--warn-container`/`--warn`, скрыт при 0 и до загрузки списка.
- Состояния: active/inactive пункта (selected — `--primary-container`).

## C-03. Button

- Варианты: `filled` (primary-действие: «Отслеживать»), `tonal` («Обновить»), `text` («Далее», «Подробнее»), `icon` (крестик, корзина, обновление).
- Размеры: md (40px высота) — основной; sm (32px) — в чипах/строках.
- Состояния: default, hover, focus, pressed, disabled, loading (спиннер вместо лейбла, ширина фиксируется).

## C-04. SearchField с автодополнением (TickerAutocomplete)

- Назначение: поиск тикера на странице пользователя.
- Состав: filled input с иконкой `search`, dropdown-результаты (строка = тикер + имя эмитента + trailing-действие «Отслеживать»).
- Поведение: дебаунс 300 мс, минимум 2 символа; навигация стрелками; Enter выбирает подсвеченный пункт; Esc закрывает dropdown.
- Состояния: empty (подсказка), typing, loading (спиннер в dropdown), results, no-results («Тикер не найден»), already-watched (пункт помечен «Уже отслеживается», кнопка disabled), error (inline-текст под полем).

## C-05. Chip-тикера (TickerChip)

- Назначение: компактное отображение тикера в карточках и строках.
- Состав: лейбл тикера (латиница, 600), опционально мини-иконка статуса.
- Состояния: default, watched (добавляется точка/звёздочка `notifications_active`), past (приглушён `--past`).

## C-06. Карточка собрания (MeetingCard)

- Назначение: единица сетки календаря S1.
- Состав: TickerChip + имя эмитента; строка «Собрание: дд.мм.гггг»; строка «Отсечка: дд.мм.гггг» или «не объявлена»; DeadlineIndicator; маркер «отслеживается».
- Состояния: default, hover (подъём по стилю из визуального гайда), selected/focus (кольцо), прошедшее (весь контент на 60% opacity, индикатор серый), skeleton.
- Взаимодействие: клик/Enter открывает C-08 (детали).

## C-07. Индикатор срока отсечки (DeadlineIndicator)

- Назначение: единая визуализация статуса сторожка/карточки (см. `2026-10-19_индикация-сроков_ui.md`).
- Состав: иконка + цветной чип-подложка + текст («21 день», «7 дней», «сегодня», «нет даты», «прошла»).
- Варианты (по канонической шкале Р-4): `far` (subtle), `near` (info), `hot` (warning; граница — персональный `threshold_days`, по умолчанию 7), `critical` (danger, сегодня), `no_date` (neutral), `past` (muted).
- Вход: `{ status, days_to_cutoff }` из API; клиентский пересчёт порогов не выполняется (см. `2026-10-19_индикация-сроков_ui.md`, раздел 4).
- Состояния: — (статичен); обязателен текст для доступности.

## C-08. Модал деталей собрания (MeetingDetailsDialog)

- Назначение: S1.1 — детали собрания, deep-link `?meeting=<id>`.
- Состав: заголовок (тикер+эмитент), список полей (дата собрания, дата отсечки, вопрос в повестке), блок статуса сторожка с кнопкой «Отслеживать этот тикер»/«Сторожок установлен», ссылка на источник, кнопка закрытия. Суммы дивидендов не показываются (вне MVP, API таких полей не предоставляет). Ссылка на источник ведёт на `source_url`; при его отсутствии строка скрывается.
- Состояния: loading (скелетон внутри), ready, error (сообщение + «Повторить»), watched/unwatched для CTA.
- На мобильной — bottom-sheet (аналогичный контент, ручка-свайп).

## C-09. Строка сторожка (WatchRow)

- Назначение: единица списка «Мои сторожки» на S2.
- Состав: TickerChip + имя эмитента; дата отсечки или «не объявлена»; DeadlineIndicator; icon-button «Снять» (`delete`).
- Состояния: default, hover, focus, past (серый), pending-remove (во время DELETE — disabled с прогрессом), skeleton.

## C-10. Фильтры статусов сторожков (StatusFilterChips)

- Назначение: фильтрация списка сторожков («все», «горячие» = статусы `hot`/`critical` по канонической шкале, «без даты», «прошла»).
- Состав: набор toggle-чипов, один активен.
- Состояния: active/inactive/disabled (при loading списка).

## C-11. Скелетоны (Skeleton)

- Варианты: карточка собрания (C-06 skeleton), строка сторожка (C-09 skeleton), поле деталей.
- Анимация: shimmer 1.2s, цвет `--surface-3` поверх `surface-2`.

## C-12. Snackbar

- Назначение: подтверждения («Сторожок установлен», «Сторожок снят» + «Отменить») и ошибки с действием «Повторить».
- Состав: текст + опциональная action-кнопка, автозакрытие 5 сек (undo-окно), пауза по hover.
- Состояния: success (`--success`-иконка), error (`--danger`-иконка).

## C-13. Баннер состояния (StateBanner)

- Назначение: пусто / ошибка загрузки / офлайн на уровне контентной зоны.
- Состав: иконка, заголовок, подсказка, CTA («Повторить», «Далее», «Найти тикер»).
- Варианты: empty, error, offline.

## C-14. Dropdown-лист (базовый)

- Общий контейнер для подсказок автодополнения; используется только внутри C-04 в MVP. Публичным API компонента не обладает.

## Что не входит в UI-kit MVP

- Полноценный календарный грид месяца (calendar grid view) — сетка карточек по месяцам достаточна.
- Charts/графики, data-table с сортировкой по колонкам, tooltip-статистика.
- Avatar/профиль, меню пользователя, переключатель темы (тема одна — тёмная).
