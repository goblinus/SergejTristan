# Карточка компании: логотип и строка фактов (ui)

Дата: 2026-10-20
Область: ui
Статус: проект, к согласованию system-designer (ADR-0005, ADR-0006)

Назначение: зафиксировать состав, порядок и форматирование логотипа, дивидендных характеристик и дат в карточке собрания S1, строке сторожка S2 и модале деталей S1.1.

Основание: [ADR-0005](../system/adr/2026-10-20_adr-0005-dividend-metrics_system.md), [ADR-0006](../system/adr/2026-10-20_adr-0006-company-logos_system.md). Токены — [визуальный стиль](./2026-10-19_visual-style_ui.md), состав компонентов — [UI-кит](./2026-10-19_ui-component-kit_ui.md).

## 1. Термины и источники

| Характеристика | Поле API | Формат отображения | Смысл |
|---|---|---|---|
| Логотип | `logo_url` | 32×32 (36×36 в модале) | Логотип эмитента; при `null` — монограмма |
| Период | `dividend.period` | `год` / `полгода` / `квартал` | Период, за который выплачиваются дивиденды |
| На акцию | `dividend.amount_per_share` | `33,30 ₽` | Сумма дивиденда на одну акцию |
| Доходность | `dividend.yield_percent` | `8,4%` | Дивидендная доходность к последней цене акции |
| Собрание | `meeting_date` | `12.11.2026` | Дата собрания акционеров |
| Отсечка | `record_date` / `next_record_date` | `09.11.2026` | Дата закрытия реестра |
| DSI | `dsi` | `82` | Индекс стабильности дивидендов, 0–100 |

Все значения приходят с бэкенда готовыми: фронтенд **не пересчитывает** доходность и DSI. Для S2 метрики приходят в `next_dividend`, даты — в `next_meeting_date` и `next_record_date`.

Если значение не раскрыто (`null`), показывается `—`.

## 2. Порядок в карточке S1 (C-06)

Сверху вниз:

1. Логотип + тикер + имя эмитента, маркер «отслеживается» (★).
2. Строка фактов из пяти ячеек: «Период», «На акцию», «Доходность», «Собрание», «Отсечка».
3. Индикатор срока (C-07).
4. **DSI — последним элементом карточки**, справа в нижней строке, после индикатора срока.

```
┌────────────────────────────────────────────────┐
│ [logo] SBER  Сбербанк                       ★  │
│ Период   На акцию   Доходность   Собрание  Отсечка
│ год      33,30 ₽    8,4%         12.11.2026 09.11.2026
│ ──────────────────────────────────────────────  │
│ [ ●◦ 20 дней до отсечки ]          DSI 82 (i)  │
└────────────────────────────────────────────────┘
```

Даты и метрики — один визуальный уровень (одна строка из пяти колонок). Отдельного блока дат под метриками нет.

## 3. Порядок в строке S2 (C-09)

Строка сторожка — трёхстрочная карточка в списке:

1. Логотип + тикер + имя эмитента; справа — иконка «Снять».
2. Строка фактов из пяти ячеек (тот же порядок).
3. Нижняя строка: индикатор срока, **DSI последним справа**.

```
┌──────────────────────────────────────────────────────────────┐
│ [logo] SBER  Сбербанк                                    🗑  │
│ Период   На акцию   Доходность   Собрание   Отсечка          │
│ год      33,30 ₽    8,4%         12.11.2026 09.11.2026      │
│ [ ●◦ 20 дней ]                                    DSI 82 (i)│
└──────────────────────────────────────────────────────────────┘
```

На мобильной ширине пять колонок сохраняются с уменьшенным кеглем; даты не переносятся на вторую строку.

## 4. Модал деталей S1.1 (C-08)

В заголовке — логотип 36×36 и название компании. В списке полей после «Вопрос о дивидендах»: «Выплаты за период», «Выплата на акцию», «Доходность»; строка «DSI» — последняя, после «Источник». Подсказка DSI работает так же, как в карточках.

## 5. Логотип

- Размер 32×32 (карточка, строка), 36×36 (модал); радиус 8–9 px, `object-fit: contain`.
- Источник — `logo_url` из API (ADR-0006). Хотлинк с сайтов эмитентов не используется.
- `logo_url === null` или ошибка загрузки → монограмма: первая буква тикера на `--surface-3`, тот же размер.
- Логотип декоративный (`alt=""`): рядом всегда есть название компании; клик по логотипу не открывает карточку отдельно.

## 6. Форматирование

- Денежные суммы: русская локаль, два знака после запятой, неразрывный пробел между тысячами, `₽` через пробел: `1 300,00 ₽`.
- Проценты: один знак после запятой, `%` без пробела: `8,4%`.
- Даты: `дд.мм.гггг`, табличные цифры.
- DSI: целое 0–100, без `%`.
- Период: строчными — `год`, `полгода`, `квартал`.
- Подписи ячеек: 10 px / 12 px, `--on-surface-muted`; значения: 12–13 px / 18 px, `--on-surface`, `tabular-nums`.
- В карточке S1 подпись «Период» — сокращение для характеристики «выплаты за период» (полная формулировка не помещается в пять колонок).

## 7. Подсказка DSI

Кнопка-иконка `i` (16×16, круглая, граница `--outline`) стоит сразу после значения DSI и является единственным интерактивным элементом внутри карточки, не открывающим детали собрания.

Текст подсказки (единый для всех экранов):

> DSI — индекс стабильности дивидендов, 0–100. Учитывает регулярность и изменчивость выплат за последние 5 лет: чем выше, тем стабильнее дивидендный поток. 80+ — высокая стабильность, 50–79 — средняя, ниже 50 — низкая.

Поведение:

- показ по наведению мыши и по фокусу с клавиатуры; скрытие — при уходе курсора/фокуса;
- подсказка появляется над иконкой, выравнивание по правому краю, ширина 250 px, `--surface-4`, радиус 8 px, тень модала, 12 px / 16 px;
- подсказка не перехватывает клики (`pointer-events: none`);
- клик по иконке и нажатие Enter/Space **не открывают** модал собрания;
- для скринридеров текст подсказки задан `aria-label` кнопки; визуальный пузырь помечен `aria-hidden="true"`.

## 8. Состояния

| Состояние | Поведение |
|---|---|
| Загрузка | Скелетон карточки/строки с полосой под факты и заглушкой логотипа |
| Значение `null` | `—` в соответствующей ячейке; строка не скрывается |
| Нет отсечки | В ячейке «Отсечка» `—`, карточка остаётся |
| Нет логотипа | Монограмма; размеры не меняются |
| Прошедшее собрание | Факты показываются как есть; приглушение — по C-06/C-09 |
| DSI `null` | `DSI —` с фокусируемой иконкой подсказки |
| Мобильная ширина | Пять колонок сохраняются, кегль уменьшается; даты не переносятся |

## 9. Доступность

- Каждая ячейка — пара «подпись → значение» в `dl`; значение читается после подписи.
- Логотип декоративный, не дублирует название для скринридера.
- DSI не кодируется цветом: число и подпись всегда видимы.
- Иконка подсказки имеет видимое кольцо фокуса 2 px `--primary`.
- Контраст подписей — не ниже 4.5:1.

## 10. Что не входит

- Графики и история выплат, сравнение с сектором.
- Редактирование метрик и загрузка логотипов из интерфейса.
- Цветовая шкала DSI.
