# Визуальный стиль — тёмная Material-тема

Дата: 2026-10-19
Область: ui

База: Material Design 3 (Material You) в тёмном варианте. Токены ниже — единственный источник истины для фронтенда (CSS-переменные/тема Vuetify 3 или UnoCSS/Tailwind-пресет — выбор за фронтендерами, значения фиксированы здесь).

## 1. Цветовая палитра (токены)

### 1.1. Поверхности и фон

| Токен | HEX | Применение |
|---|---|---|
| `--bg-base` | `#121214` | фон приложения (за scaffold) |
| `--surface-0` | `#161618` | scaffold/фоны секций |
| `--surface-1` | `#1D1D20` | AppBar, карточки уровня 1, bottom-nav |
| `--surface-2` | `#232327` | карточки собраний, строки таблицы |
| `--surface-3` | `#2B2B30` | modal, dropdown подсказок, snackbar |
| `--surface-4` | `#313137` | hover-слои поверх surface-3, bottom-sheet |

Цвет overlay'ев elevation не применяем (чистые поверхности, различие по тону — как в таблице). Границы: `--outline` `#3A3A40`, `--outline-variant` `#2A2A2E`.

### 1.2. Текст и контент

| Токен | HEX | Применение |
|---|---|---|
| `--on-surface` | `#E6E1E8` | основной текст |
| `--on-surface-variant` | `#C9C5CF` | вторичный (подписи, метки) |
| `--on-surface-muted` | `#8E8B96` | даты в прошедшем, disabled-текст |

### 1.3. Акценты

| Токен | HEX | Применение |
|---|---|---|
| `--primary` | `#9DB8FF` | активная вкладка, ссылки, primary-кнопки (тёмно-синий indigo-акцент, читается на тёмном) |
| `--on-primary` | `#0B1026` | текст на primary |
| `--primary-container` | `#2A3454` | фон selected/tonal-элементов |
| `--on-primary-container` | `#C6D4FF` | текст на primary-container |

### 1.4. Семантика сроков и статусов

| Токен | HEX | Семантика |
|---|---|---|
| `--warn` | `#FFD54F` | статус `hot` — отсечка в пределах порога сторожка (`threshold_days`, по умолчанию 7 дней), предупреждения |
| `--on-warn` | `#3A2E00` | текст на жёлтом |

| `--past` | `#57575E` | «прошла»: приглушённые элементы |

Связь токенов с логикой сроков — см. `2026-10-19_индикация-сроков_ui.md`.

## 2. Типографика

Шрифт: **Inter** (лицензия Open Font License) для UI, системный фолбэк: `-apple-system, "Segoe UI", Roboto, sans-serif`. Цифры — табличные (`font-feature-settings: "tnum"`) в датах и счётчиках дней, чтобы не прыгала ширина.

| Стиль | Размер/вес | Применение |
|---|---|---|
| `headline-sm` | 24/32, 600 | заголовок страницы (если понадобится) |
| `title-lg` | 20/28, 600 | название в AppBar, заголовок modal |
| `title-md` | 16/24, 600 | заголовки секций («Предстоящие», «Мои сторожки») |
| `body-lg` | 16/24, 400 | тикер + эмитент в карточке |
| `body-md` | 14/20, 400 | основной текст, даты |
| `label-lg` | 14/20, 500 | кнопки, чипы |
| `label-md` | 12/16, 500 | подписи индикаторов срока, «обновлено N мин назад» |

Моноширинный шрифт не используем в MVP.

## 3. Отступы, сетка, радиусы

- Шаг сетки: **4px**. Базовые значения: 4, 8, 12, 16, 20, 24, 32.
- Поля контентной колонки: 24px (десктоп), 16px (мобайл); max-width контента 1200px.
- Внутренние отступы карточки/строки: 16px по горизонтали, 12–16px по вертикали.
- Радиусы: карточка/модал — 16px; чип/индикатор — 8px (или pill 999px для чипов статусов); кнопка — 20px (pill); текстовое поле — 12px (filled) / 4px top corners в filled-стиле.
- Расстояние между карточками сетки: 16px. Между секциями: 24–32px.

## 4. Элевация и линии

Без тяжёлых теней на тёмной теме; слои различаем тоном поверхности (раздел 1.1) и тонкой границей.

| Компонент | Элевация | Доп. |
|---|---|---|
| AppBar | `surface-1` + нижняя граница 1px `--outline-variant` | — |
| Карточка собрания | `surface-2` | hover: подъём до `surface-3` без тени |
| Modal / dropdown | `surface-3` + тень `0 8px 24px rgba(0,0,0,.45)` | + граница `outline-variant` |
| Snackbar | `surface-3` + та же тень | на 4px скруглении 8px |

## 5. Состояния интерактива (state layers)

| Состояние | Правило |
|---|---|
| hover | поверхность + overlay `--on-surface` 8% поверх |
| focus | видимое кольцо 2px `--primary` с offset 2px; focus-visible обязателен (клавиатурная навигация) |
| pressed | overlay `--on-surface` 12% |
| selected | фон `--primary-container`, текст `--on-primary-container` |
| disabled | прозрачность текста/иконок 38%, фон `--on-surface` 12%; без hover/focus эффектов |

## 6. Иконки

Набор: **Material Symbols (Rounded)**. Размеры: 20px в кнопках/чипах, 24px в AppBar и навигации. Используемые в MVP: `calendar_month`, `event`, `search`, `add`, `close`, `delete`, `notifications`/`notifications_active` (сторожок), `warning`, `error`, `check_circle`, `schedule`, `refresh`, `info`.

## 7. Доступность (минимум для MVP)

- Контраст текста к фону ≥ 4.5:1 (все пары токенов выше дают ≥ 7:1, кроме `--on-surface-muted` — только для крупных/декоративных, не для важных данных).
- Статус срока воспроизводится текстом и иконкой, не только цветом.
- Все действия доступны с клавиатуры: навигация по карточкам/строкам стрелками, Enter — открыть/применить, Esc — закрыть modal.
- `aria-live="polite"` на snackbar и на зонах загрузки/ошибки.
