# Вайрфреймы основных экранов (low-fi, ASCII)

Дата: 2026-10-19
Область: ui

Назначение: зафиксировать компоновку и состав элементов до проектирования компонентов во фронтенде. Точные размеры — в `2026-10-19_визуальный-стиль_ui.md`.

Обозначения: `[ ]` — кнопка/интерактив; `( )` — иконка; `▢` — чекбокс/переключатель; `████` — скелетон-заглушка.

## S1. Календарь собраний (десктоп ≥ 1024px)

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ◇ Дивидендный календарь      [ Календарь ] [ Мои сторожки ●3 ]    (⟳)  (? )│  ← AppBar, surface-1; ●3 — бейдж-счётчик hot/critical (Р-9), скрыт при 0
├──────────────────────────────────────────────────────────────────────────────┤
│ Фильтры:  Месяц: [◀ Октябрь 2026 ▶]     ▢ Показать прошедшие                │  ← панель фильтров
│           Найдено: 24 собрания · Обновлено 5 мин назад                       │
├──────────────────────────────────────────────────────────────────────────────┤
│ Предстоящие                                                                 │
│ ┌────────────────────────┐ ┌────────────────────────┐ ┌────────────────────────┐
│ │ SBER  Сбербанк         │ │ GAZP  Газпром          │ │ LKOH  Лукойл           │  ← карточки собраний
│ │ ●                      │ │ ★ отслеживается        │ │ ●                      │
│ │ Собрание:  12.11.2026  │ │ Собрание:  20.11.2026  │ │ Собрание:  03.12.2026  │
│ │ Отсечка:   09.11.2026  │ │ Отсечка:   16.11.2026  │ │ Отсечка:   30.11.2026  │
│ │ [ ●◦ До отсечки 21 д ] │ │ [ ◐ До отсечки 28 д ]  │ │ [ ●◦ До отсечки 42 д ] │
│ └────────────────────────┘ └────────────────────────┘ └────────────────────────┘
│ ┌────────────────────────┐ ┌────────────────────────┐ ┌────────────────────────┐
│ │ ...                    │ │ ...                    │ │ ...                    │
│ └────────────────────────┘ └────────────────────────┘ └────────────────────────┘
│                                                                              │
│ Прошедшие (свёрнуто ▸)                                                       │
└──────────────────────────────────────────────────────────────────────────────┘
```

Ключевые элементы:
- Карточка собрания: тикер + имя эмитента, дата собрания, дата отсечки, чип-индикатор срока, пометка «отслеживается» (★) если тикер в сторожках.
- Секция «Прошедшие» сворачивается, чтобы не отвлекать.
- Метка «Обновлено 5 мин назад» строится по минимальному `fetched_at` показанных записей (поле добавляется в API по решению Р-6); **при отсутствии `fetched_at` метка скрывается**, фильтры и счётчик найденного показываются как обычно.

Примечания к S1.1:
- Суммы дивидендов не показываются: в MVP собираются только даты и повестка (суммы не моделируются, backend/API их не предоставляет).
- Ссылка «Источник» ведёт на `source_url` собрания; **при отсутствии `source_url` в ответе API строка источника скрывается** (поле добавляется в контракт по решению Р-6).
- Суммы вне MVP; детали ограничены датами, повесткой, статусом сторожка и ссылкой на первоисточник.

- Сортировка: ближайшая дата сверху; «нет даты» после датированных; «прошла» — в конце (и серым).

## Правила компоновки (сводно)

- Контентная колонка: max-width 1200px, центрирование, поля 24px (десктоп) / 16px (мобайл).
- Межкомпонентные отступы кратны 4/8px; секции отделяются 24px.
- Карточки календаря — сетка: 3 колонки ≥1024px, 2 колонки 640–1024px, 1 колонка <640px.
- Индикатор срока всегда читабелен текстом (не только цветом): «21 день», «7 дней», «нет даты», «прошла» — требование доступности.
- Модал деталей: max-width 560px, скрывается по Esc, клику по оверлею, кнопке (✕).
