# SergejTristan

Выпускная работа практического курса по вайб-кодингу на [Claude Code](https://claude.com/claude-code).

## О проекте

**Дивидендный календарь** — сервис для отслеживания дивидендных событий по компаниям российского фондового рынка.

Пользователь может установить «сторожок» на одну или несколько компаний и следить за приближением даты собрания акционеров и выплаты дивидендов.

### Состав сервиса

- **Фронтенд** — интерфейс для настройки календаря (выбора компаний) и просмотра информации:
  - текущие извещения и ближайшие даты собраний акционеров;
  - результаты прошедших собраний: факт выплаты/невыплаты дивидендов, их размер и дата выплаты.
- **База данных** — хранилище информации о компаниях, собраниях и дивидендных выплатах.
- **Система получения данных** — сбор сущфактов из официальных источников: moex.com, disclosure.ru и т.п.
- **Система парсинга и нормализации** — приведение полученных данных к единому формату и их сохранение в базе данных.

## Подход к разработке

Проект разрабатывается в парадигме вайб-кодинга: основная часть кода создаётся во взаимодействии с Claude Code. В работе придерживаемся следующих принципов:

- изменения в файлы проекта вносятся только после подтверждения;
- перед установкой недостающих инструментов и библиотек запрашивается разрешение;
- для анализа данных предпочтителен Python.

## Именование файлов

Создаваемые файлы именуются по шаблону:

```
дата_название-файла_тип.расширение
```

- `дата` — дата создания в формате `ГГГГ-ММ-ДД`;
- `название-файла` — наименование файла или источника данных (слова через дефис);
- `тип` — название папки, где находится файл (`docs`, `reports`, `scripts` и т.п.);
- `расширение` — формат данных (`csv`, `md`, `json` и т.п.).

Пример: `2026-09-24_расчет-вклада_docs.csv`.
