# SergejTristan

Выпускная работа практического курса по вайб-кодингу на [Claude Code](https://claude.com/claude-code).

## О проекте

**Дивидендный календарь** — автообновляемый сервис для непрофессиональных личных инвестиций на российском фондовом рынке.

### Функциональность MVP

- список тикеров Московской биржи;
- календарь собраний акционеров, на которых решается вопрос о выплате дивидендов;
- хранение дат дивидендной отсечки (дата закрытия реестра) перед собранием акционеров;
- «сторожок»: пользователь выбирает тикеры и отслеживает приближение даты дивидендной отсечки;
- страница пользователя для выбора отслеживаемых тикеров.

### Состав сервиса

- **Фронтенд** — JavaScript/TypeScript, Vue.js 3, тёмная Material-тема. Интерфейс календаря, ленты извещений и страницы пользователя.
- **Бэкенд** — Python, SQLAlchemy, Pydantic (uv для зависимостей).
- **База данных** — хранилище информации о тикерах, собраниях, датах отсечки и «сторожках».
- **Набор инструментов (скрипты)** — сбор сущфактов из официальных источников (moex.com, disclosure.ru и т.п.), их нормализация и сохранение в базу данных.

## Подход к разработке

Проект разрабатывается в парадигме вайб-кодинга: основная часть кода создаётся во взаимодействии с Claude Code. В работе придерживаемся следующих принципов:

- изменения в файлы проекта вносятся только после подтверждения;
- перед установкой недостающих инструментов и библиотек запрашивается разрешение;
- для анализа данных предпочтителен Python.

## Именование файлов

Создаваемые файлы именуются по шаблону:

```
дата_название-файла_тип.расширение
```

- `дата` — дата создания в формате `ГГГГ-ММ-ДД`;
- `название-файла` — наименование файла или источника данных (слова через дефис);
- `тип` — название папки, где находится файл (`docs`, `reports`, `scripts` и т.п.);
- `расширение` — формат данных (`csv`, `md`, `json` и т.п.).

Пример: `2026-09-24_расчет-вклада_docs.csv`.
