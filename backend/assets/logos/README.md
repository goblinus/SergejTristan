# Логотипы эмитентов

Каталог курируемых SVG-логотипов для скрипта `scripts/sync_logos.py`
(см. `design/backend/2026-10-19_collect-scripts-specifications_backend.md`,
ADR-0006).

## Конвенция именования

- Имя файла — тикер MOEX в верхнем регистре и расширение `.svg`:
  `SBER.svg`, `GAZP.svg`, `LKOH.svg`.
- Тикер сравнивается без учёта регистра: `sber.svg` соответствует `SBER`.
- Один файл на эмитента. При дубликатах (различающихся регистром) берётся
  первый по алфавиту, остальные логируются WARNING.
- Файл должен быть корректным XML с корневым элементом `<svg>`
  (namespace `http://www.w3.org/2000/svg` допустим). Битый или не-SVG файл
  пропускается с WARNING, тикер остаётся без логотипа (`logo_url = NULL`).

## Синхронизация

```bash
uv run python -m scripts.sync_logos [--dry-run] [--verbose]
```

Скрипт копирует валидные файлы в `static/logos/{TICKER}.svg` (только при
отсутствии или изменении содержимого) и проставляет относительный путь
`/static/logos/{TICKER}.svg` в `tickers.logo_url` для всех тикеров. Файлы
здесь не хотлинкаются с сайтов эмитентов: набор пополняется вручную.
