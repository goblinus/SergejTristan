# Бэкенд «Дивидендного календаря»

API для фронтенда, сбор сущфактов из официальных источников (moex.com, disclosure.ru), парсинг и нормализация данных, хранение в БД.

## Стек

Python, uv (зависимости и окружение), SQLAlchemy (БД), Pydantic (модели и валидация). Веб-фреймворк, СУБД, планировщик — по спецификациям `design/backend/`, согласованным system-designer (см. ADR в `design/system/adr/`).

## Источники истины

- Схема БД, API-контракты, архитектура модулей: `design/backend/`.

Реализуются только спецификации, согласованные system-designer. Неполная или противоречивая спецификация — не додумывать, вернуть задачу с вопросом.

## Границы

- Изменения только внутри `backend/`.
- Перед установкой зависимостей — запрос разрешения у владельца.
- Перед записью/изменением файлов — подтверждение у владельца.
